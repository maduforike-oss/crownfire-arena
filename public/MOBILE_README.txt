CROWDFIRE ARENA - MOBILE BUILD

Recommended installation:
1. Host the contents of this folder on an HTTPS web host.
2. Open the URL on your phone in landscape orientation.
3. Android/Chrome: choose Install App or Add to Home Screen.
4. iPhone/Safari: tap Share, then Add to Home Screen.

Touch controls:
- Left directional pad: move
- BOMB: place rune bomb
- POWER: champion special
- HEX: detonate Remote Hex bombs
- Pause symbol: pause the match

The game supports multi-touch, so movement and action buttons can be held/pressed together.
